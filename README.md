# Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit
This project presents a framework for the adiabatic idealization of metadynamics. In this framework, the position of each hill is sampled from the equilibrium distribution in the total potential, $F(x) + V_{bias}(x)$. In our approach, the equilibrium distribution is reached instantly. This is made possible by the predefined free energy profile, $F(x)$. The simulations aim to establish a benchmark for metadynamics algorithms [1]. Additionally, the project involves postprocessing HILLS files generated by the PLUMED program.

# Installation
The package can be installed directly from GitHub using the following command:
pip install git+https://github.com/olga-r/Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit.git

Alternatively, the package can be cloned and installed using the following command:
pip install .

# Usage

1. Change to your working directory and type `metad_config` in the console. Two files will be created: `custom_potential.py` and `job_config.json`.
   - **a)** Only $F(x) = \text{constant}$ is implemented by default; however, it is possible to set the potential to `"custom"` in `job_config.json` and modify `custom_potential.py` so that the custom function returns your custom $F(x)$ (see examples). The name of the function that generates the potential must be specified in the job_config.json file under the `"func_name"` parameter (e.g., "func_name": "custom").
   - **b)** In `job_config.json` select:
     - `"method"`: `"bounds"` (finite interval), `"interval"` (method interval [2]), `"periodic"`, `"mcgovern_interval"` ([3]); `mcgovern_interval` works only with `metad_gentraj`
     - `"metad_mode"`: `"wt"` (well-tempered) or `"standard"` (height of the hills is constant)
     - `"potential"`: `"constant"`, `"custom"` or `"none"` (`"none"` is the special case that works only with `metad_readhills`). 
     - `"kernel_mode"`: `"unit_peak"` or `"unit_integral"`. This option describes hill normalization. To align with PLUMED, it is necessary to select `"unit_peak"`.
     - `"height"`: the value of the height of the Gaussian function
     - `"sigma"`: the value of the $\sigma$ of the Gaussian function
     - `"bias_factor"`: the value of the bias factor, $\gamma$, in well-tempered metadynamics
     -  `"kBT"`: the value of the temperature factor kT
     - `"min"` and `"max"` are the boundaries of the interval for which the FES should be restored
     - `"out_min"` and `"out_max"` are the external boundaries of the grid for the "interval" and "mcgovern_interval" methods.
     - `"n_grid"`: the number of bins in the interval `["min", "max"]`
     - `"periodic_tol"`: the maximum allowable error when truncating an infinite sum for a periodic kernel. This error determines the point at which the "tail" of a Gaussian distribution is small enough to be neglected 
     - `"total_steps"`: the total number of steps (length) of the simulation
     - `"chunk_size"`: the physical size of each I/O operation
     - `"stride"`: the frequency with which the results are saved by the `metad_gentraj` and `metad_readhills`
     - `"plot_stride"`: the frequency with which the $p_w$ distribution is plotted by the `metad_target_distr` 
     - `"base_dir"`:  working directory
     - `"filename"`: filename to output metad_gentraj or metad_readhills results
     - `"hill_file"`: path to the PLUMED HILL file, only necessary for metad_readhills program
     - `"filter_width"`: 1.5,
     - `"peak_threshold"`: 1.0,
     - `"seed"`: 8456835
2. Type `metad_gentraj` in your working directory to generate a new trajectory
3. Type `metad_readhills` in your working directory to read and recalculate your PLUMED hills file
   `metad_readhills` without potential does nothing other than read the hills file generated by PLUMED and then return the internal metadynamics time for each step.
4. Type `metad_target_distr` in your working directory. This will enable the analysis of the results. 
   
   The standard output provides:
   - The internal time of metadynamics.
   - The KL distance between the current and target distribution.
   - The file `p.npy` containing distributions in the total potential (biased + original).
   - The file `mass_in_peaks.txt` illustrating the proportion of the normalised distribution that falls into narrow peaks ($\text{std} < 0.005 \times L$, where $L$ is the length of the interval `[min, max]`).
