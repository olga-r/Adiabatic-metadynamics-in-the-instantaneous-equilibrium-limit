# Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit
This project presents a framework for the adiabatic idealization of metadynamics. In this framework, the position of each hill is sampled from the equilibrium distribution in the total potential, $F(x) + V_{bias}(x)$. In our approach, the equilibrium distribution is reached instantly. This is made possible by the predefined free energy profile, $F(x)$. The simulations aim to establish a benchmark for metadynamics algorithms. See reference [1] for more details. Additionally, the project involves postprocessing HILLS files generated by the PLUMED program.

# Installation
The package can be installed directly from GitHub using the following command:
pip install git+https://github.com/olga-r/Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit.git

Alternatively, the package can be cloned and installed using the following command:
pip install .

# Usage

1. Change to your working directory and type `metad_config` in the console. Two files will be created: `custom_potential.py` and `job_config.json`.
   - **a)** Only $F(x) = \text{constant}$ is implemented by default; however, it is possible to set the potential to `"custom"` in `job_config.json` and modify `custom_potential.py` so that the custom function returns your custom $F(x)$ (see examples). The name of the function that generates the potential must be specified in the job_config.json file under the `"func_name"` parameter (e.g., "func_name": "custom").
   - **b)** In `job_config.json` select:
     - `"method"`: `"bounds"` (finite interval), `"interval"` (method interval [2]), `"periodic"`, `"mcgovern_interval"` ([3]); `mcgovern_interval` works only with `metad_gentraj`
     - `"metad_mode"`: `"wt"` (well-tempered) or `"standard"` (height of the hills is constant)
     - `"potential"`: `"constant"`, `"custom"` or `"none"` (`"none"` is the special case that works only with `metad_readhills`). 
     - `"kernel_mode"`: `"unit_peak"` or `"unit_integral"`. This option describes hill normalization. To align with PLUMED, it is necessary to select `"unit_peak"`.
     - `"height"`: the value of the height of the Gaussian function
     - `"sigma"`: the value of the $\sigma$ of the Gaussian function
     - `"bias_factor"`: the value of the bias factor, $\gamma$, in well-tempered metadynamics
     -  `"kBT"`: the value of the temperature factor kT
     - `"min"` and `"max"` are the boundaries of the interval for which the FES should be restored
     - `"out_min"` and `"out_max"` are the external boundaries of the grid for the "interval" and "mcgovern_interval" methods.
     - `"n_grid"`: the number of bins in the interval `["min", "max"]`
     - `"periodic_tol"`: the maximum allowable error when truncating an infinite sum for a periodic kernel. This error determines the point at which the "tail" of a Gaussian distribution is small enough to be neglected 
     - `"total_steps"`: the total number of steps (length) of the simulation
     - `"chunk_size"`: the physical size of each I/O operation
     - `"stride"`: the frequency with which the results are saved by the `metad_gentraj` and `metad_readhills`
     - `"plot_stride"`: the frequency with which the $p_w$ distribution is plotted by the `metad_target_distr`. To disable plotting of $p_w$, set `plot_stride` to less than or equal to 0.
     - `"base_dir"`:  working directory
     - `"filename"`: filename to output the `metad_gentraj` or `metad_readhills` results
     - `"hill_file"`: the path to the PLUMED hill file. This is only necessary for the `metad_readhills` program.
     - `"filter_width"`: the sigma parameter in SciPy's ndimage.gaussian_filter1d. We use gaussian_filter1d to smooth the logarithm of the probability distribution before detecting the peaks.
     - `"peak_threshold"`: the prominence parameter in SciPy's signal.find_peaks function. We use this function to detect delta-like peaks in the probability distribution.
     - `"seed"`: the random seed value
2. In your working directory, type `metad_gentraj` to generate a new trajectory
3. In your working directory, type `metad_readhills` to read and process your PLUMED HILLS file.
   Note that `metad_readhills` cannot calculate the $p_w$ and $p_b$ probability distributions without a predefined potential $F(x)$.
4. In your working directory, type `metad_target_distr` to analyze the results obtained by the 'metad_gentraj' and 'metad_readhills' programs. 
   
   The standard output provides the following:
   - the "time.txt" file, which contains four time definitions: md step, metadynamics time ($\tau$), introduced by [4], replicator time ($\theta$), and replicator time ($s$). Without a predefined potential $F(x)$, we obtain an asymptotically unbiased estimator of the times $\theta$ and $s$
   - the "KL_distance.txt" file, which contains the Kullback–Leibler divergence between the current and target distributions
   - the "mass_in_peaks.txt" file, which contains the mass that falls into narrow peaks
   - the "centers.txt" file, which contains the coordinates of the Gaussian centers
   - the "grid_centers.txt" file, which contains the positions of the grid centers
   - the "bias_V_pb.npy" file, which contains the bias potential that was saved with the `"stride"` parameter
   - the "bias_V_w.npy" file, which contains the bias potential scaled by $\frac{\alpha}{\beta}$, where $\beta=\frac{1}{kT}$, $\alpha = \beta + \frac{1}{k\Delta T}$, $\gamma = 1+\frac{\Delta T}{T}$, and $\gamma$ is a bias factor. For standard metadynamics, $\alpha=\beta$
   -  the "bias_U.npy" file, which contains the bias potential scaled by $\alpha$ 
   -  the "pb.npy"  file, which contains the distributions in the $F(x) + V_{bias}(x)$ potential
   - the "pw.npy"  file, which contains the distributions in the $F(x) + \frac{\alpha}{\beta}V_{bias}(x)$ potential
   - the "heights.txt" file, which contains the heights of the deposited hills and the heights scaled by $\frac{\alpha}{\beta}$.
