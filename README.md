# Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit
The following project outlines a framework for adiabatic metadynamics simulations using a predefined free-energy profile F(x). The objective of this project is to establish a benchmark for metadynamics algorithms.

# Installation
The package can be installed directly from GitHub using the following command:
pip install git+https://github.com/olga-r/Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit.git

Alternatively, the package can be cloned and installed using the following command:
pip install .

# Dependencies
- numpy
- scipy
- numba
- h5py

# Usage
1) Change to your working directory and type "metad_config" in the console. Two files will be created: custom_potential.py and job_config.json.
a) Only F(x) = constant is implemented by default; however, it is possible to set Potential to "Custom" in job_config.json and modify custom_potential.py so that the custom function returns your custom F(x).
b) In job_config.json select:
-"method": "bounds" (finite interval), "interval" (method interval [1]), "periodic", "mcgovern_interval" ([2]); mcgovern_interval works only with "metad_gentraj"
-"metad_mode": "wt" (well-tempered) or "normal" (height of the hills is constant)
-"potential": "constant", "custom" or "none" ("none" is the special case that works only with "metad_readhills"). The metad_readhills without potential performs no other action than to read the hills file generated by plumed, and subsequently returns the inner metadynamics time for each step.
-"kernel_mode": "unit_peak"  "unit_integral". This option describes the normalization  of the hill. To align with PLUMED,  it is necessary to select "unit_peak".
-"min" and "max" are the boundaries of the interval for which the FES should be restored
-"out_min" and "out_max" should be the same as the "min" and "max" in all cases except when the "interval" method is chosen. In this context, they are used to indicate the external boundaries of the grid.
-"n_grid" - the number of bins in the interval ["min", "max"]
-"height" and "sigma"  are the parameters of the Gaussian function
-"bias_factor" is needed only if well-tempered metadynamics is chosen. Just leave it as is if you are doing standard metadynamics
-"total_steps" is the length of the simulation
-"chunk_size" defines the physical size of each I/O operation.
-"stride" means how often the results are saved
-"deposition_pace" - how often hills are deposited in the plumed hills file. This option is valid only for "metad_readhills". If you are running "metad_gentraj", leave it as is.
2) type "metad_gentraj" in your working directory to generate a new trajectory
3) type "metad_readhills" in your working trajectory to read and recalculate your PLUMED hills file
4) type "metad_target_distr" in your working directory.  This will enable the analysis of the results. The standard output provides the internal time of metadynamics, the KL distance between the current and target distribution, the file 'p.npy' containing distributions in the total potential (biased + original), and the file 'mass_in_peaks.txt' illustrating the proportion of the normalised distribution that fails into narrow peaks (std < 0.005*L, where L is the length of the interval [min, max]).
Please, note that for  well_tempered metadynamics the distribution in the F(x)+[bf/(bf-1)]*V(x) = const is plotted, where df is the bias factor
