# Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit
The following project outlines a framework for adiabatic metadynamics simulations using a predefined free-energy profile F(x). The objective of this project is to establish a benchmark for metadynamics algorithms.

# Installation
The package can be installed directly from GitHub using the following command:
pip install git+https://github.com/olga-r/Adiabatic-metadynamics-in-the-instantaneous-equilibrium-limit.git

Alternatively, the package can be cloned and installed using the following command:
pip install .

# Dependencies
- numpy
- scipy
- numba
- h5py

# Usage

1. Change to your working directory and type `metad_config` in the console. Two files will be created: `custom_potential.py` and `job_config.json`.
   - **a)** Only $F(x) = \text{constant}$ is implemented by default; however, it is possible to set Potential to `"Custom"` in `job_config.json` and modify `custom_potential.py` so that the custom function returns your custom $F(x)$.
   - **b)** In `job_config.json` select:
     - `"method"`: `"bounds"` (finite interval), `"interval"` (method interval [1]), `"periodic"`, `"mcgovern_interval"` ([2]); `mcgovern_interval` works only with `metad_gentraj`
     - `"metad_mode"`: `"wt"` (well-tempered) or `"normal"` (height of the hills is constant)
     - `"potential"`: `"constant"`, `"custom"` or `"none"` (`"none"` is the special case that works only with `metad_readhills`). `metad_readhills` without potential does nothing other than read the hills file generated by PLUMED and then return the internal metadynamics time for each step.
     - `"kernel_mode"`: `"unit_peak"` or `"unit_integral"`. This option describes hill normalization. To align with PLUMED, it is necessary to select `"unit_peak"`.
     - `"min"` and `"max"` are the boundaries of the interval for which the FES should be restored
     - `"out_min"` and `"out_max"` should be the same as the `"min"` and `"max"` in all cases except when the `"interval"` method is chosen. In this context, they are used to indicate the external boundaries of the grid.
     - `"n_grid"`: the number of bins in the interval `["min", "max"]`
     - `"height"` and `"sigma"` are the parameters of the Gaussian function
     - `"bias_factor"` is needed only if well-tempered metadynamics is chosen. Just leave it as is if you are doing standard metadynamics
     - `"total_steps"` is the length of the simulation
     - `"chunk_size"` defines the physical size of each I/O operation.
     - `"stride"` denotes how often the results are saved.
2. Type `metad_gentraj` in your working directory to generate a new trajectory
3. Type `metad_readhills` in your working directory to read and recalculate your PLUMED hills file
4. Type `metad_target_distr` in your working directory. This will enable the analysis of the results. 
   
   The standard output provides:
   - The internal time of metadynamics.
   - The KL distance between the current and target distribution.
   - The file `p.npy` containing distributions in the total potential (biased + original).
   - The file `mass_in_peaks.txt` illustrating the proportion of the normalised distribution that falls into narrow peaks ($\text{std} < 0.005 \times L$, where $L$ is the length of the interval `[min, max]`).
